# 数据来源说明

## 用途

这个文件用来说明“日报每天应该从哪里抓取什么内容，以及每类来源的用途是什么”。

这里存放的是给人和 agent 阅读理解的说明。
机器可读的数据源配置放在 [data/source-accounts.json](/E:/zhijiang/data/source-accounts.json)。

## 来源分类

当前项目将数据来源分为四类：

1. 公司与团体官方账号
2. 成员官方账号与直播间
3. 切片员账号与切片观察位
4. 第三方直播数据网站

## 来源与板块映射

### 每日直播日程表

主要来源：

- `https://asoul.love/` 上的枝江五位成员每周直播日程表
- 成员直播间
- 官方账号动态中的排班或预告内容

### 昨日直播数据

主要来源：

- 成员直播间
- 第三方直播数据网站

### 昨日高播放切片

主要来源：

- 切片员账号
- 平台搜索结果与切片观察位

当前筛选规则：

- 默认只抓取播放量 `>= 6000` 的切片视频
- 如果后续需要补充“潜力切片”或“刚发布高增速切片”，再单独定义次级候选规则

### 昨日热点总结与反馈

主要来源：

- 公司官方动态
- 团体官方动态
- 成员官方动态
- 切片评论区

## 每条来源建议保留的字段

每条来源记录建议尽量包含以下字段：

- `id`
- `label`
- `type`
- `group`
- `member`
- `platform`
- `url`
- `dynamicUrl`
- `uid`
- `roomId`
- `enabled`
- `purpose`
- `notes`
- 如果来源不是全量相关，建议额外补充主题过滤说明

## 更新规则

当新增链接时：

1. 先更新本文件，补充人类可读说明
2. 再更新 `data/source-accounts.json`，补结构化记录
3. 如果出现了新的来源类型，再同步更新 `docs/architecture.md`

## 当前抓取阈值与过滤约定

- 切片抓取当前默认最低播放量阈值为 `6000`
- 纯枝江 / A-SOUL 相关切片员可长期纳入候选池，但仍建议保留视频级主题过滤
- 游戏向切片员仅在成员直播内容明确与“鸣潮”或“战双”相关时纳入候选池
- 直播日程应优先结合 `asoul.love`、成员直播间和官号动态进行交叉确认
