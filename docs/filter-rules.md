# 主题过滤规则

这个文件用于定义“什么内容算和枝江日报主题相关”，供切片抓取、候选排序、热点总结与评论区抽样共用。

## 设计目标

- 让切片抓取不被无关视频淹没
- 让不同来源的候选内容能用同一套标准判断
- 先给出第一阶段可执行的规则，后续再根据误判情况微调

## 适用范围

这套规则当前主要用于：

- 切片员视频候选过滤
- 平台搜索结果过滤
- 热点总结来源筛选
- 评论区抽样时的上游视频筛选

## 一、默认判断顺序

建议按以下顺序判断一条视频是否纳入候选：

1. 先过基础阈值
2. 再过成员 / 团体相关性
3. 再判断是否命中特定主题
4. 最后决定候选类别与优先级

## 二、基础阈值

当前默认基础阈值：

- 视频播放量必须 `>= 6000`

如果不满足这条，默认不纳入“昨日高播放切片”候选池。

例外情况后续再单独定义，目前第一阶段不开放例外。

## 三、直接相关命中规则

只要视频标题、简介、标签、评论置顶、投稿文案中明确命中以下任一类信息，就可判为直接相关候选。

### 3.1 成员名命中

当前应识别这些成员名：

- `嘉然`
- `乃琳`
- `贝拉`
- `心宜`
- `思诺`

### 3.2 团体名命中

当前应识别这些团体或项目名：

- `A-SOUL`
- `A-Soul`
- `asoul`
- `枝江`
- `枝江娱乐`
- `闪耀舞台`

### 3.3 直接相关判定

满足以下任一情况，可直接判为相关：

- 命中成员名
- 命中团体名
- 同时命中直播内容和成员 / 团体语境

这类结果的 `relevanceType` 可记为：

- `direct_asoul`
- `direct_zhijiang`

## 四、游戏主题命中规则

这一组规则主要用于“游戏向切片员”。

### 4.1 当前支持的游戏主题

- `鸣潮`
- `战双`

### 4.2 游戏向切片员启用条件

如果来源账号属于“游戏向切片员”，则需要同时满足：

1. 视频播放量 `>= 6000`
2. 内容中命中以下任一成员 / 团体相关信息：
   - 成员名
   - `A-SOUL`
   - `枝江`
3. 内容中命中以下任一游戏主题：
   - `鸣潮`
   - `战双`

三者同时满足时，才纳入候选池。

这类结果的 `relevanceType` 记为：

- `game_related`

## 五、来源类型对应规则

### 5.1 纯枝江 / A-SOUL 相关切片员

这类账号默认视为高可信来源，当前第一阶段不再额外要求“成员 / 团体命中”才能入池。

也就是说：

- 只要来源账号属于这一组
- 且视频播放量 `>= 6000`

就默认纳入候选池。

说明：

- 这是当前阶段的简化规则，用来避免对高相关切片员做过度过滤
- 如果后续发现这组账号中也开始稳定出现较多无关内容，再回头补视频级排除规则

这类结果默认可记为：

- `relevanceType = direct_asoul`
  或
- `relevanceType = direct_zhijiang`

### 5.2 游戏向切片员

这类账号不能只靠“账号在名单里”就直接通过：

- 必须同时命中成员 / 团体信息
- 必须同时命中 `鸣潮` 或 `战双`

### 5.3 平台搜索结果

搜索结果建议使用更保守策略：

- 必须命中成员名
- 或者命中团体名且语义明确相关

如果只是泛泛提到 `枝江`、`asoul` 但没有明确内容相关，应暂时降权或排除。

## 六、排除规则

以下情况建议直接排除或默认降为无效候选：

- 游戏向切片员只命中游戏主题，不命中成员 / 团体
- 平台搜索结果只命中泛 V 圈语境，不命中枝江日报关注对象
- 播放量低于 `6000`
- 明显与当前日报主题无关的搜索结果或候选视频

## 七、建议的实现字段

后续实现过滤器时，建议至少产出这些判断字段：

- `matchedMembers`
- `matchedGroups`
- `matchedTopics`
- `relevanceType`
- `sourceCategory`
- `filterPassed`
- `filterReason`

其中：

- `matchedMembers`：命中的成员数组
- `matchedGroups`：命中的团体 / 项目数组
- `matchedTopics`：命中的主题数组
- `filterPassed`：布尔值
- `filterReason`：说明通过或淘汰原因

## 八、判断示例

### 示例 1：直接相关，通过

标题：

`嘉然昨晚直播高能整活片段合集`

判断：

- 命中成员：`嘉然`
- 播放量如果 `>= 6000`
- 直接通过

结果：

- `relevanceType = direct_asoul`

### 示例 1.1：纯枝江切片员，通过

标题：

`直播回顾：整活高能片段速览`

来源：

纯枝江 / A-SOUL 相关切片员

判断：

- 来源账号已经在高相关名单中
- 播放量如果 `>= 6000`
- 当前第一阶段直接通过，不再额外要求标题里命中成员名

结果：

- `filterPassed = true`
- `relevanceType = direct_zhijiang`

### 示例 2：游戏向，通过

标题：

`嘉然鸣潮跑图名场面`

来源：

游戏向切片员

判断：

- 命中成员：`嘉然`
- 命中主题：`鸣潮`
- 若播放量 `>= 6000`，通过

结果：

- `relevanceType = game_related`

### 示例 3：游戏向，不通过

标题：

`鸣潮新角色剧情过场合集`

来源：

游戏向切片员

判断：

- 命中主题：`鸣潮`
- 未命中成员 / 团体
- 不通过

结果：

- `filterPassed = false`
- `filterReason = missing_member_or_group_match`

## 九、后续维护规则

以下变化发生时，应优先更新本文件：

- 新增新的主题型切片员分组
- 新增新的游戏主题
- 播放量阈值变化
- 成员或团体范围变化
- 平台搜索策略变化
