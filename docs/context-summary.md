# 阶段总结

这个文件不是完整工作日志，也不是完整对话记录。
它的作用是保存“当前阶段持续有效的共识”，让后续 agent 在上下文不完整时，仍能快速知道项目现在处于什么状态。

## 这个文件应该记录什么

- 当前项目整体状态
- 最近完成的结构性工作
- 当前主要风险与阻塞
- 接下来最建议推进的事项
- 最近几天工作日志里提炼出的高价值摘要

## 这个文件不应该记录什么

- 每一次零散对话
- 过细的逐条操作过程
- 仅当天有效、很快就失效的临时讨论
